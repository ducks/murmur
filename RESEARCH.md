# Research notes

## Hypothesis and initial design

A persistent, locally coupled dynamical graph may provide useful temporal representations for sequence learning. The broader, untested hypothesis is that local plasticity and structural changes could improve adaptation and retention. Here 128 units receive fixed random symbol inputs and synchronous weighted messages from four randomly sampled incoming edges. Each state is a leaky interpolation of its old value and the tanh of its current input. States stay bounded when initialized in [-1,1]. Output weights alone learn via online logistic delta updates: a synapse uses its input unit's activation and the output's broadcast target-minus-prediction error. This is a supervised, nonlocal error signal shared among readout synapses, not an entirely local learning system. It was chosen for inspectability and a clear control, not as a claim of biological plausibility.

The strongest alternative explanation is that the leaky state alone holds the cue; recurrent messages might be unnecessary. The readout has access to all units and can decode this direct trace. Random input projections and binary targets make the task especially easy. The current experiment does not establish a benefit from graph connectivity, self-organization, learned internal representations, compositional generalization, continual learning, or structural growth. See the experiment document for actual results.

## Relationship to prior work

- This design is closest to **reservoir computing / echo state networks**: a fixed recurrent dynamical system with a trained readout. See [Jaeger's original report](https://www.ai.rug.nl/minds/uploads/EchoStatesTechRep.pdf). It is not a claim of novelty.
- [Neural cellular automata](https://distill.pub/2020/growing-ca/) use repeated local state updates, often with learned shared update rules and spatial neighborhoods. This prototype uses a random directed graph and no learned cellular update or growth.
- [Predictive coding](https://doi.org/10.1038/4580) uses prediction errors in a structured inference process. Our supervised readout error is not such a system.
- Hebbian and structural plasticity change connections using activity and other signals; neither is implemented here. A useful next comparison is [structural plasticity in neural networks](https://doi.org/10.1038/nrn.2016.98).
- [Hopfield attractor networks](https://doi.org/10.1073/pnas.79.8.2554) study recurrent associative dynamics and stable memories; our graph has no demonstrated attractor memory. [Self-organizing maps](https://doi.org/10.1007/BF00337288) organize representations through competition and neighborhood adaptation, neither of which is present here.
- [Continual learning](https://doi.org/10.1073/pnas.1611835114) highlights interference and retention; independent reset trials do not evaluate them. Graph dynamical systems and recurrent networks broadly precede this work.

## Failure modes and next steps

Memory may fade quickly, random projections may be inefficient, a dense supervised readout may dominate, and error-driven growth could overfit noise or cause instability. Fixed seed success does not show robustness. Next, test longer and variable delays, including an edge-free leaky-state control, then investigate internal learning only if it improves a controlled baseline. Before growth, define sustained error criteria, causal fixed-topology comparisons, resource budgets, and structural event logs. Subsequent work should test probabilistic sequences, interference, changing rules, and genuinely withheld compositions. Runtime, memory, resource-matched baselines, configurable structural limits, serializable input configs, full model checkpoints, growth, pruning, and wider ablations remain unimplemented.

## Follow-up: what do the edges contribute?

The delayed-memory experiment compares the recurrent graph with a clone whose edges are removed. In the tested settings both reached identical accuracies, including perfect results for delays up to four markers and near-chance results from delay twelve. Self-retention is sufficient for the short task; the first result did not demonstrate a benefit from communication. A constant trained bias can dominate a weak but nonzero memory trace, so accuracy alone cannot separate representation loss from readout optimization failure. See [EXPERIMENTS.md](EXPERIMENTS.md).

## Proposed next experiment: internal learning

We can begin now, while retaining the fixed graph as the control. Start with fixed topology and a bounded, explicit activity-dependent edge update, plus an eligibility trace that links earlier pre/post activity to the later prediction error. Compare learned edges with identical initial frozen edges and an error-shuffled control, keeping readout training, data, seed, and number of examples matched. Measure prediction across delays and edge-weight changes, and evaluate frozen weights on fresh trials. The first risk is credit assignment: a scalar output error does not by itself specify which hidden edge caused it; a naive Hebbian rule may reinforce frequent correlations without improving the objective. A meaningful success must exceed variability across seeds and the edge-free control, not merely change weights. Tune on separate seeds and reserve test seeds; do not add growth until the learning rule and its controls are understood. This is a proposal, not an implemented or validated rule.

## Internal learning: first result

A fixed-topology, activity-trace rule with supervised error feedback changed recurrent weights but did not improve held-out accuracy versus either frozen weights or a one-trial-shifted-feedback control across ten seeds at delays 4, 8, and 12. The readout and graph were trained together, so this does not disentangle an altered representation from readout adaptation. Exploratory diagnostics found shrinking cue-dependent state differences and, at delay 12, score margins on the same side of the decision boundary for both cues. These observations do not prove that all cue information is lost or explain why the edge rule failed. Full protocol and numerical results are in [EXPERIMENTS.md](EXPERIMENTS.md).

A useful next investigation is to compare a separately fitted linear probe on frozen states and quantify training dynamics, before increasing rule complexity. The heuristic pre/post eligibility is not a derivative of the final loss, and supervised feedback through readout weights is not purely local. The one-trial-shift control also does not guarantee independent feedback. Evaluate these caveats before claiming credit assignment or continual adaptation.

## Separating graph state from readout performance

A post-hoc, separately fitted nearest-centroid linear probe recovered both cues perfectly from the clean frozen graph states through 24 marker steps across seeds 21–30, while the original online readout was near chance at delays 8–24. This shows that the original reader's failure is not proof the graph states have become identical. The clean test is easy because the same two deterministic states appear in training and evaluation. At delay 24, adding independent uniform observation noise with half-width 0.001 reduced mean probe accuracy to 0.689, indicating fragility under that artificial perturbation. This does not establish behavior under internal dynamical noise, unseen patterns, or plasticity-trained graphs. See [EXPERIMENTS.md](EXPERIMENTS.md).

## Varied inputs and internal noise

The frozen graph's clean, repeated-marker success does not translate to longer sequences of varied distractors: on a sequence-disjoint test split, the online readout and centroid probe were both near chance by 12 distractors across seeds 31–40. At four varied distractors the online readout succeeded while the centroid probe averaged 0.763, so probe failure does not prove information is absent. With repeated markers, internal noise of half-width 0.01 reduced the 24-step probe accuracy from 1.000 to 0.508. Both readers trained and tested under the same noise condition. See [EXPERIMENTS.md](EXPERIMENTS.md) for protocol, split caveats, and results.

## Adaptive online sequence engine

The first practical sequence engine uses symbol units and directed predictive edges. Its local row update is an exponential moving average of one-step transitions, mathematically equivalent to a recency-weighted Markov model. This explicit equivalence is a limitation and a control, not architectural novelty. On the four-symbol noisy rule-change experiment, the engine adapted rapidly relative to a frozen copy and cumulative counts, but lost the old rule on counterfactual queries. The fixed-capacity, one-symbol state cannot distinguish two conflicting rules without an additional context signal. This engine is separate from the prior 128-unit reservoir and does not implement growth, pruning, long-range memory, or graph self-organization. See [EXPERIMENTS.md](EXPERIMENTS.md) for results, baselines, and caveats.

The next research question is whether persistent context can support distinct rules for the same symbol without destroying old transitions, and whether a graph-based mechanism can outperform an equally capable context-aware Markov baseline. Test explicit context first to establish what information is needed; unsignaled rule inference is a separate harder problem.

## Explicit context

A context-cued extension assigns distinct transition weights to each `(context, source)` pair, retains a single previous symbol through switches, and receives the cue before every prediction. In ten noisy-stream runs it retained both trained rules and performed well on alternating contexts; a context-aware count baseline matched it. The original context-free engine overwrote its old predictions after the second rule and suffered adaptation lag when the rules alternated. This is expected from hard separation and external routing, not evidence of an emergent representation. The context-aware model has twice as many edges as the context-free model. It remains equivalent to a context-conditioned recency-weighted Markov model and does not infer its own contexts. See [EXPERIMENTS.md](EXPERIMENTS.md).

Next, examine unlabeled or ambiguous context inference against simple hidden-state baselines and include explicit uncertainty: with overlapping evidence, the active rule cannot always be known instantly. Do not interpret a supplied label as discovered structure.

## Unannounced context switches

A two-state Bayesian filter can combine the existing labelled-trained edge tables to infer which known rule is active during a fresh stream without receiving evaluation labels. In ten exploratory runs it predicted the next symbol at 0.843 accuracy, versus 0.865 for the same filter with count-trained tables, 0.902 for a true-context oracle using graph tables, and 0.613 for the context-free adaptive engine. Context accuracy after observing the current transition was 0.943. It was often wrong on the first symbol after a switch; later context classification cannot be treated as advance prediction. This system is a standard hidden Markov model over two pre-specified, supervised-learned contexts, not self-organization or unsupervised rule discovery. See [EXPERIMENTS.md](EXPERIMENTS.md).

The next meaningful test is learning or adapting rule models without supplied labels, with uncertainty and a context-aware hidden-state learning baseline. Additional unknown contexts, ambiguous emissions, unknown switch rates, and memory retention remain open; introducing growth without a causal comparison would not answer them.

## Unsupervised rule discovery and the growth failure

A two-state online hidden-state mixture learned both dominant transition rules without rule labels on ten simple switching streams. A model allowed to grow from one to two memories achieved 0.853 frozen-test prediction accuracy, comparable to 0.856 for the same mixture initialized with two memories. However, its fixed sustained-surprise threshold grew a redundant memory on **all ten stationary runs**, at both 10% and 25% noise. In one inspected 10% stationary run, ten unexpected predictions in 50 steps sufficed to trigger two high-surprise windows. Thus this is evidence that the candidate mixture can fit this task, but negative evidence for the proposed growth criterion. The comparison baseline is the same algorithm at fixed capacity, not an independent HMM implementation. See [EXPERIMENTS.md](EXPERIMENTS.md).

Before adding complexity or presenting growth as self-organization, investigate calibrated change detection and compare growth against a no-growth model with predictive likelihood and complexity cost. Evaluate false-alarm rates over longer stationary streams, varied noise and switching rates, use separate development and evaluation seeds, and compare with independently implemented HMM/change-point baselines. The current two-memory cap, globally computed posterior, and fixed heuristic are prototype constraints; no pruning, merging, or local structural dynamics are implemented.

## Candidate trial and complexity penalty

A new table can now be evaluated as a temporary branch: train candidate and control on the same 100 observations, freeze their weights for the next 100, and commit the candidate only if its total predictive log-loss improvement exceeds a fixed penalty. A penalty of 40 selected on development seeds produced acceptance in 20/20 switching runs and 1/20 stationary runs at each of 10% and 25% noise on separate test seeds. The trial model's frozen-test accuracy on switching streams was 0.855 versus 0.857 for a fixed two-table baseline and 0.467 for a single table. This is a promising result for the tested streams, not a calibrated general false-alarm guarantee: alarms are repeated, the stream and schedule are simple, the threshold was selected after inspecting development outcomes, candidate comparisons pause learning, and no independent change-point baseline or computation budget was evaluated. An improvement in predictive log loss can reflect better calibration or noise fitting rather than discovery of a new rule. See [EXPERIMENTS.md](EXPERIMENTS.md).

## Stress-testing growth decisions

With the previously chosen penalty unchanged, the temporary-candidate method committed in 20/20 runs with 50-step switches, 19/20 with 100-step switches, and 14/20 with 200-step switches. At 10% noise, stationary false commits increased from 1/20 over 1,200 steps to 9/20 over 5,000 steps. A separately implemented CUSUM-style count-model alarm, selected on separate development seeds, missed all 50-step switching streams but alarmed in 2/20 long 10%-noise stationary streams. The alarm only reports a change and is not a memory-learning model. These limited samples reveal window sensitivity and repeated-testing risk; they do not establish calibrated long-run error rates or a fair compute-matched ranking. See [EXPERIMENTS.md](EXPERIMENTS.md).

Next investigate sequential tests that account for repeated attempts, candidate training windows spanning multiple contexts, and varying change rates. Preserve a no-growth control and measure total computation and decision latency. Avoid tuning further on the test seeds used here.

## A heuristic for repeated attempts

A penalty that increases as `40 + scale × ln(attempt)` reduced long stationary false commits on one separate 20-seed test group while retaining the observed switching-run commits: scale 0 yielded 11/20 and 3/20 false-commit runs at 10% and 25% noise; scales 20, 40, and 80 yielded 1/20 and 0/20. Switching commits were 19/20 and 20/20 for 100- and 200-step blocks at every tested scale. The samples are small, the variants were explored together, and the previous seed group had weaker 200-step detection. The adaptive comparison scores do not satisfy a demonstrated sequential-testing guarantee, so this must not be described as calibrated error control. See [EXPERIMENTS.md](EXPERIMENTS.md).

## Parallel alternative prototypes

Three isolated prototypes explored different directions; their datasets, metrics, and budgets differ, so their accuracy figures must not be compared directly.

- [Sparse local associative graph](alternatives/local_graph/README.md): a Hopfield-style 128-unit graph uses local Hebbian edge updates and asynchronous neighbor dynamics to complete corrupted stored patterns. Exact recall fell sharply as more patterns shared the graph; at 16 patterns its mean bit accuracy was below simply retaining the corrupted cue. This is a genuine locally interacting substrate, but the evaluation is associative completion of previously stored patterns, not sequence learning or novel architecture.
- [Online run-length model](alternatives/latent_context/README.md): a Bayesian change-point model predicts streams without context labels and relearns after changes. It traded performance with a two-memory mixture across different switching rates, while requiring substantially more computation and not recalling old contexts explicitly. Its results are online prediction, not the frozen-test protocol of the main growth experiments.
- [Independent change alarms](alternatives/change_detection/README.md): a separate Bayesian change-point alarm and CUSUM-style alarm were calibrated on stationary development runs and tested on separate streams. At the chosen thresholds the Bayesian alarm missed every scored switch and raised stationary false alarms; CUSUM caught some slower switches but missed the faster ones. These models only raise alarms and do not learn memories. Results are negative for those settings, not a general rejection of Bayesian change detection.

All standalone tests and main-project tests passed in the Nix shell. The promising architectural question is whether the local graph's pattern completion can be combined with sequence-appropriate representations while retaining a strong direct-lookup control; a meaningful next experiment should also measure interference and continually added patterns rather than assume the associative result transfers to language.

## Local graph on sequence completion

The local associative graph was tested on completing a missing fourth symbol from noisy encoded prefixes of stored four-symbol sequences. At 20% prefix-bit corruption, its accuracy fell from 1.000 for two stored sequences to 0.444 for 32; a nearest-prefix lookup remained at or above 0.986. With clean prefixes the graph still fell to 0.475 at 32, which is consistent with capacity/interference rather than noise alone. This is static pattern completion with position-specific codes and familiar stored sequences, not an online sequence processor or a compositional generalization test. The lookup has a different storage/computation profile. See [the full protocol](alternatives/local_graph/README.md).

Next investigate the graph's failure before adding complexity: compare local fields and retrieval errors by load, use a direct nearest-stored-pattern classifier and graph ablations, and test whether graph competition or coding choices affect interference. If the aim shifts to novel-sequence prediction, introduce distinct held-out sequences and process symbols over time rather than calling positional pattern completion temporal learning.

## Diagnosing local-graph errors

Target-only training on the same topology achieved perfect sequence completion in the tested conditions, while the full 32-sequence graph achieved 0.463 on clean random-coded prefixes. At the correct full pattern, other learned patterns canceled or reversed a positive target-only field for 10.6% of output units. These interventions support cross-memory interference, although target-only selection is an oracle and the field measurement does not replicate the graph's actual unknown output state. Making distinct symbols' codes exactly orthogonal within each position raised the 32-sequence score only to 0.476; it did not remove shared symbol blocks across sequences. Removing feedback among output units yielded 0.484, and one sweep gave 0.451. Thus accidental same-position code correlation and repeated settling are not sufficient explanations on their own. The investigation is limited to this encoding, topology, learning rule, and familiar training sequences; see [protocol and results](alternatives/local_graph/README.md).

A next controlled intervention would test mean-centering or covariance-style updates to reduce correlations from frequent symbols, with the same data, frozen evaluation and lookup baseline; an improvement would need new seeds and separate parameter-selection data. The current findings do not justify claiming the mechanism has been fixed.

## Research leads for associative interference and evaluation

- [Storkey (1997), Increasing the Capacity of a Hopfield Network without Sacrificing Functionality](https://homepages.inf.ed.ac.uk/amos/publications/Storkey1997IncreasingtheCapacityoftheHopfieldNetworkwithoutSacrificingFunctionality.pdf) proposes an incremental learning rule that uses local fields to reduce interference. It is a concrete next comparison to our plain Hebbian update; its original capacity analysis does not guarantee improvement for our sparse, clamped, correlated sequence task.
- [Kanter and Sompolinsky (1987), Associative recall of memory without errors](https://doi.org/10.1103/PhysRevA.35.380) studies a projection-based associative memory and correlated-pattern limitations. A projection or pseudoinverse-style method could be a useful stronger reference; its access to global pattern relationships makes it a different locality/compute tradeoff, not an automatic Murmur solution.
- [Golomb, Rubin, and Sompolinsky (1990), Willshaw model](https://doi.org/10.1103/PhysRevA.41.1843) examines sparse coding in associative memory. Sparse activity and competitive selection are relevant alternatives to the current dense bipolar representation, but need fair sweeps and controls.
- [Lake and Baroni (2018), SCAN](https://proceedings.mlr.press/v80/lake18a.html) demonstrates systematically withheld compositions as an evaluation of sequence generalization. It is a later benchmark once the system can process sequences over time; the current stored-pattern completion task is a different problem.
- [Hugging Face Datasets local loading](https://huggingface.co/docs/datasets/main/loading) can support optional data interchange and reproducible splits. It does not supply the learning rule. Preserve the no-external-service constraint, generate and retain data locally, and keep held-out compositions disjoint; generic random row splits alone do not establish compositional generalization.

Proposed comparison: Hebbian versus an accurately implemented sparse-graph Storkey-style local-field rule and optional centered/covariance rule; same generated sequences, graph topologies, corruptions, inference, and held-out seeds. Add a projection-style global reference only with an explicit accounting of its information and compute requirements. Measure retrieval by load, corruption, time, storage, retention, and repeated learning; retain nearest-prefix lookup. Select any hyperparameters on separate seeds, then test on unseen seeds. Structural splits and online input require separate tasks; do not call fresh corruptions of memorized sequences novel-sequence generalization. These are plans, not observed results.

## Research runner first slice

A small task-specific [runner](toolkit/README.md) now saves the sequence-completion configuration, stored sequences, shared evaluation cues, all predictions, per-seed metrics, provenance gaps and execution status. Its full example run matched all 40 corresponding original per-seed metrics for trained, lookup, untrained, and majority models. This improves inspectability; it does not add a learning rule or provide independent evidence. It does not yet implement a generic model interface, resource measurements, unseen-sequence splits, or pinned environment provenance.

## Storkey-style local-field learning

A sparse-topology adaptation of the [Storkey learning rule](https://homepages.inf.ed.ac.uk/amos/publications/Storkey1997IncreasingtheCapacityoftheHopfieldNetworkwithoutSacrificingFunctionality.pdf) improved this familiar-sequence retrieval task relative to Hebbian learning at loads of 4, 8, and 16 on separate test seeds (0.951 vs 0.909, 0.770 vs 0.698, and 0.602 vs 0.558). At 32, it was slightly worse (0.436 vs 0.449), while lookup reached 0.983. Its target-state oracle field-flip diagnostic was lower, yet that did not guarantee better decoding at the largest load. This is an encouraging but bounded result: evaluation uses corrupted cues of stored sequences, not unseen sequence generalization. Training and storage measurements are implementation-specific and not budget matched. See [EXPERIMENTS.md](EXPERIMENTS.md) for seeds, formula, diagnostics, and the corrected initial memory-accounting error.

Next investigate why reduced oracle field reversals do not ensure better completion at high load: compare output-bit margins and trajectories, code correlations, memory order and capacity across several noise levels. Use a fresh seed group for any selected change and retain the lookup control; do not assume Storkey's full-network capacity analysis transfers to this sparse, clamped, correlated-pattern problem.

## Small graphs with external routing

For 32 stored sequences at 20% prefix-bit noise, four separately initialized 128-unit graphs storing eight memories each improved accuracy compared with one 128-unit graph. On 20 separate test seeds, single/oracle-routed/nearest-prefix-routed accuracy was 0.454/0.695/0.690 for Hebbian graphs and 0.431/0.772/0.765 for Storkey-style graphs. Router shard accuracy was 0.985; direct lookup was 0.986. The assignment was externally balanced, and the router searches stored prefixes using essentially the lookup baseline's algorithm, so neither self-organized division nor learned local routing has been demonstrated. Four graphs also use roughly four times the graph payload; a matched-512-unit single-graph comparison is absent. Timings and protocol are in [EXPERIMENTS.md](EXPERIMENTS.md).

## Matched connection-storage sharding test

A single 256-unit graph and four 128-unit graphs each use 589,824 bytes for their dense weight/mask payload in the current implementation; the four-graph system also stores a 1,024-byte external prefix router on this platform. At 20% cue corruption, across 20 new test seeds, the single large graph with duplicated input codes achieved 0.448 Hebbian / 0.456 Storkey-style accuracy; routed four-graph variants achieved 0.683 / 0.756, while lookup achieved 0.985. A post-hoc sensitivity control giving the 256-unit graph independent extra codes scored 0.455 / 0.490. Sharding was better in each paired seed in these tested settings.

This is evidence for the concrete partitioned system under a roughly matched **connection-array storage** budget, not proof that specialization universally wins: four graphs have more units, a supplied assignment, and a router that already searches stored examples; the large graph uses different encodings and topology, and the independent-code condition has extra noisy input. Test sequences were previously stored, and the sensitivity control was added after inspecting initial outcomes. See [EXPERIMENTS.md](EXPERIMENTS.md) for clean/noisy results, measurements and limitations.
